# Cornerstone：双足交替式爬楼机构设计

Cornerstone 是一个面向楼梯环境的载物机构设计项目。项目通过双足交替支撑与嵌套式连杆布局，让载物平台在跨越台阶时保持相对稳定，探索机械结构在无电梯建筑中的搬运应用。

> 项目在早期 proposal 中也称“**双足嵌套式载物爬楼机构**”；专利证书采用的名称为“**一种双足交替式攀爬机构**”。

![Cornerstone 机构三维总装效果](images/final-assembly-render.png)

| 项目 | 内容 |
| --- | --- |
| 项目类型 | 机械结构设计与原型验证 |
| 核心问题 | 让载物机构适应不同高度、宽度的楼梯，并尽量保持载荷稳定 |
| 关键方案 | 双足交替支撑、嵌套式连杆、可拆卸载物筐、齿轮传动 |

## 项目背景

轮组、履带和多足机构各有优势，但在楼梯场景中往往需要在地形适应性、载荷稳定性、结构复杂度和运动灵活性之间取舍。Cornerstone 将“稳定载物”作为核心目标，尝试用较简单的双足交替机构完成跨阶运动，为老旧建筑中的物品搬运提供一种机械结构方向。

## 机构方案

机构由以下部分组成：

- 一个驱动马达与主体传动结构
- 一个可拆卸的长方体载物筐
- 两组锥状机械足
- 两组切比雪夫连杆机构
- 一根承重杆与若干连接杆

承重杆两端分别连接一组机械足。马达带动齿轮组和传动机构，使两侧机构按交替节奏完成支撑、抬升、跨越和落脚。嵌套式布局为结构收纳和跨阶运动留出空间，载物筐则承担对不同尺寸物品的适配需求。

## 设计流程

1. 对轮组、履带、多足和复合式爬楼方案进行对比，明确稳定载物与结构简化的设计取向。
2. 设计可调节的载物平台，并分析平台与爬楼机构之间的连接方式。
3. 完成双足嵌套机构的方案推演、结构建模与运动验证。
4. 制作 3D 打印零件，进行实体装配和运动测试，根据测试结果调整结构。
5. 整理机构方案与技术材料，形成专利成果。

## 设计亮点

- **交替支撑**：用两侧机械足分担支撑与跨阶动作，关注爬楼过程中的连续承载。
- **嵌套式结构**：将连杆与机械足组合在有限空间内，兼顾结构紧凑性与台阶适应性。
- **稳定载物**：载物筐采用可拆卸设计，便于适配不同尺寸和用途的载荷。
- **实体验证**：从概念草图推进到 3D 打印零件与样机装配，让机构方案接受真实装配和运动条件检验。
- **专利转化**：项目方案最终形成实用新型专利授权，完成从概念设计到知识产权成果的闭环。
